# Deuce — el marcador miente

Web de análisis post-partido del circuito ATP. No cuenta quién ganó: cuenta lo que el resultado se calla. Cincuenta y cinco medidas por partido, 36 temporadas del circuito principal y, para los partidos anotados golpe a golpe, un análisis profundo con el partido reproducible punto a punto.

Se actualiza sola cada mañana (`.github/workflows/nocturno.yml`). La guía de puesta en marcha está en `GUIA.md`.
